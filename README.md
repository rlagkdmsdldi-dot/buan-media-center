# 부안미디어센터 홈페이지

- 공개 주소: https://rlagkdmsdldi-dot.github.io/buan-media-center/
- 관리자 페이지: https://rlagkdmsdldi-dot.github.io/buan-media-center/admin.html

## 구성
- `index.html` 홈페이지
- `admin.html` 관리자 페이지 (로그인 후 내용 추가·수정)
- `config.js` 관리 서버(구글 Apps Script) 주소
- `defaults.js` 관리자 페이지에서 아직 저장하지 않은 항목의 기본 내용
- `pixel-pals.js` 픽셀 캐릭터
- `apps-script/Code.gs` 관리 서버 코드 (구글 Apps Script에 붙여넣어 배포)
- `forms/` 신청서 양식, `facilities/` 시설 사진, `thumbs/` 영상 썸네일
